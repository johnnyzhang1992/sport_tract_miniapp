## 二、后端环境变量（服务器 .env / docker-compose）

| 变量 | 必填 | 说明 |
|---|---|---|
| `MONGODB_URI` | ✅ | **轮换后**的新连接串（含新密码） |
| `JWT_SECRET` / `JWT_REFRESH_SECRET` | ✅ | **严禁用默认 `dev-insecure-*`**，随机长串 |
| `ADMIN_PASSWORD` | ✅ | **严禁默认 admin123456**，上线必改 |
| `ADMIN_JWT_SECRET` | ✅ | 独立 admin 密钥，随机 |
| `WX_APPID` / `WX_SECRET` | ✅ | 正式环境关 `WX_MOCK_LOGIN` |
| `OSS_*`（AK/桶/区域） | ✅ | bucket `sports-track` 保持私有 |
| `TENCENT_MAP_KEY` | 可选 | 纠偏/逆地理（已失效需重配 + IP 白名单） |
| `CORS_ORIGIN` | 按需 | 逗号分隔多白名单；**webAdmin 同域部署则无需** |
| `PORT=3004` | ✅ | nginx 转发目标 |

## 三、nginx（history-docker，已改）

```nginx
# api.conf
location /sport-track/ { proxy_pass http://sport-track-api:3004; }  # 路径原样透传
# 其他服务：再加 location /xxx/ { proxy_pass ...; }
```

- 改完需重启 nginx 容器才生效
- 旧路径 `/api/*` 将 404——确认前端都走了新前缀
- 部署后端时 `docker compose up -d --build sport-track-api`（npm ci + bcryptjs 需 package-lock 同步）

## 四、webAdmin 部署（sport.historybook.cn 独立子域）

### 域名与证书（需人工）
1. **DNS**：`sport.historybook.cn` A 记录 → 服务器 IP（124.220.54.45）
2. **证书**：申请 `sport.historybook.cn` 证书，放入 `nginx/cert/`：
   - `sport.historybook.cn_bundle.pem` + `sport.historybook.cn.key`

### 部署步骤
1. webAdmin：`pnpm build` → 产物复制到 `history-docker/webadmin-dist/`（nginx 挂载目录，.gitignore 排除）
2. nginx：`nginx/sport.conf` 已就位（80→301；443：`/` 静态 webadmin + `/sport-track/` 反代后端）
3. 后端 CORS：服务器 `.env` 设 `CORS_ORIGIN=https://sport.historybook.cn`（逗号分隔可加多个）→ 重启 sport-track-api
4. `docker compose up -d --build nginx`（或仅重启 nginx 生效新挂载）
5. 登录：admin + 部署时设置的 `ADMIN_PASSWORD`（bcrypt 存库可改）

> API 地址：生产构建注入 `VITE_API_BASE=https://api.historybook.cn/sport-track/api`
> （跨子域调用，靠 CORS 白名单放行；dev 走 vite 代理相对路径）。
