# 08-轨迹纠偏实现（当前逻辑快照）

> 记录时间：2026-08-12。用途：测试基线，后续调整参照。

## 一、架构链路

```
wx.onLocationChange (实时)
  └─ tracker.addPoint()          前端实时过滤（节流/精度/速度/尖刺回滚）
       └─ 轨迹点含 accuracy（水平精度 m）
finish 时上传全部点
  └─ 后端 finishActivity()
       ├─ cleanAltitudeSpikes()   海拔尖刺清洗（置 null）
       ├─ cleanTrajectory()       轨迹纠偏（剔点）★ 本文件重点
       ├─ smoothTrackSmart()      轨迹平滑（滑动平均+位移守卫）
       └─ calcStats()             重算 距离/配速/卡路里/爬升
reprocess 接口（详情页「🧹 纠偏」按钮）对历史数据重跑同一链路
```

## 二、按运动类型阈值（前后端一致）

| 类型 | 尖刺下限 m/s | 绝对超速 m/s | 单侧高速 m/s | 精度阈值 m |
|---|---|---|---|---|
| walking/hiking | 5 | 12 | 7 | 60 |
| running | 8 | 18 | 10 | 50 |
| cycling | 12 | 30 | 14 | 40 |
| mountaineering | 5 | 12 | 7 | 80 |
| swimming | 3 | 8 | 5 | 60 |

配置位置：
- 后端：`src/utils/trajectory-clean.ts` → `TYPE_CONFIGS`
- 前端：`miniprogram/services/tracker.js` → `TYPE_TRACKER_CONFIG`

## 三、后端 cleanTrajectory（四类剔除规则）

对每个中间点 i（首尾单独处理），计算：
- `d1/d2`：到前后点距离（米）
- `v1/v2`：瞬时速度 = 距离/时间差（m/s）
- `med`：窗口 ±2 点的局部速度中位数
- `turn`：a→b→c 方向转角（0~180°）

**规则 1 — 尖刺**（双向高速 + 反转）：
```
v1 > max(类型尖刺下限, med×3.5) 且 v2 > 同上 且 turn > 100° → 剔除
```
典型：短时高速来回跳（21m/1.3s=15m/s 抖动）

**规则 2 — 绝对超速**（孤立漂移）：
```
v1 > 类型绝对上限 且 v2 > 类型绝对上限 → 剔除
```
（必须双向都超，避免级联误剔超速段的正常邻居）

**规则 3 — 单侧高速跳**（同向高速/跳出跳回）：
```
(v1 > max(类型单侧高速, med×4) 或 v2 同) 且 min(v1,v2) > max(3, med×1.5) → 剔除
```

**规则 4 — 孤立离群点**（垂距大）：
```
点到前后连线距离 > max(25m, med×5) 且 d1>15m 且 d2>15m → 剔除
```

**首尾跳点**（起点 GPS 未收敛/结束漂移）：
```
首段/末段距离 > max(12m, 局部步长中位数×4) → 剔首/尾点
```

## 四、前端 tracker 实时过滤

按顺序：
1. **精度过滤**：`accuracy > 类型精度阈值` → 丢弃（不入轨迹）
2. **节流**：位移 <3m 且间隔 <3s → 丢弃
3. **速度过滤**：瞬时速度 > 类型绝对超速 → 丢弃
4. **反转过滤**：方向反转 >120° 且 速度 <2m/s（室内漂移）→ 丢弃
5. **尖刺回滚**：新点到达后，检测上一点是否"双向高速+反转"→ 是则剔除并**回退距离/爬升**（用最近 6 点速度中位数自适应）

## 五、平滑（smoothTrackSmart）

- 滑动平均窗口 5 + 位移守卫 20m（平滑后位移过大回退原值，保护急弯）
- 首尾端点保持不动
- 平滑会略微缩短距离（重算指标）

## 七、已知残留（下次测试关注）

- **小幅来回抖**（5-15m，速度 2-4m/s）：阈值内未剔除（可接受范围，Keep/悦跑圈同）
- **长间隙慢速大位移**（如 13:16:34 的 215m/2min）：可能真实移动，保留
- accuracy 字段新加：仅新记录有，旧数据无
