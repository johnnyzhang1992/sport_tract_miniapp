# 竞品分析 — 运动轨迹记录类

> 调研日期：2025-08-10
> 范围：Keep、悦跑圈、咕咚、两步路、六只脚、行者、Strava、微信运动
> 用途：支撑需求说明书（docs/01-需求说明书.md）的功能取舍

---

## 1. 分产品要点

### 1.1 Keep（跑步/健走模块）
- **记录**：GPS 实时记录，支持自由跑、目标跑（距离/时长/配速目标）、课程跑、AI 陪跑；指标：里程、时长、配速、步频、心率（配手环）、卡路里、海拔
- **分享**：轨迹地图 + 配速/心率曲线；动态分享带"跑步水印"轨迹图；跑步徽章打卡
- **统计**：运动档案看板，日/周/月/总报表、趋势图、跨品类分析
- **商业化**：会员（课程+训练计划）、线上马拉松报名费 + 定制奖牌、商城、硬件、广告
- **借鉴**：跑步水印分享图、目标跑模式、运动档案看板

### 1.2 悦跑圈
- **记录**：GPS 实时记录（自有降误差算法）、室内模式、跑鞋历程、防作弊；可暂停 1 小时内恢复、创意轨迹作画
- **分享**：轨迹水印分享图（照片+数据+轨迹图叠加）— 国内最经典分享形态
- **社区**：跑友圈、附近跑友、线上马赛事
- **商业化**：广告、赛事服务、线上马拉松报名费、电商、会员
- **借鉴**：轨迹水印分享图、锁屏防误触

### 1.3 咕咚
- **记录**：GPS 实时记录 + 智能硬件联动；支持跑步、骑行、健走、登山、越野、徒步等多类型
- **打点（重点）**：「运动瞬间」— 运动中拍照+文字记录，运动后生成回忆册分享，即"照片打点"成熟实现
- **商业化**：自营智能装备商城（最强项）、会员（含**轨迹导出**付费功能）、赛事
- **借鉴**：运动瞬间（照片打点）→ 回忆册；轨迹导出放会员

### 1.4 两步路（户外助手）
- **记录**：GPS 实时记录，无网络可用；**轨迹导入导出为核心卖点**（KML/GPX/KMZ，保留航点、时间、高度、速度）
- **社区**：轨迹广场（数千万条轨迹）、循迹导航、路网、离线地图、语音播报、轨迹纠偏
- **商业化**：VIP 会员、装备商城、赛事、商业活动（领队认证）
- **借鉴**：GPX/KML 导入导出保留航点信息

### 1.5 六只脚
- **记录**：GPS 轨迹记录 + **多媒体"脚印"打点（文字/图片/视频脚印）— 行业打点标杆**；实时经纬度、总时间、总里程、速度、平均速度、海拔
- **地图**：街景/卫星/地形/等高线/OSM 6 种地图、离线地图
- **平台**：350 万+轨迹库、云同步、分享讨论
- **商业化**：弱（B 端 SAAS 与内容变现探索）
- **借鉴**：文字/图片/视频脚印打点模型

### 1.6 行者骑行
- **记录**：GPS 轨迹记录，**自定义数据表盘**；骑行+跑步+徒步+滑雪+游泳
- **分享**：运动长图（数据+地图+照片，标准/卫星地图、1:1/4:3 比例）、网页链接分享轨迹
- **商业化**：PRO 会员（爬坡分析、运动热图、轨迹合并、3D 轨迹）、智能硬件、电商
- **借鉴**：分享长图多比例多地图样式

### 1.7 Strava（国外标杆）
- **记录**：GPS 实时记录跑步/骑行/徒步，免费版即完整记录+社交
- **差异化**：Segment 路段排名系统（KOM/QOM）、3D Flyover（付费）、活动照片标记、挑战赛、成就徽章
- **商业化**：订阅制（免费记录 + $79.99/年增值）— 最成功的"工具免费+数据增值付费"模式
- **借鉴**：照片标记、成就徽章（轻量版）

### 1.8 微信运动 / 微信底层能力
- 不提供轨迹记录，但提供：`wx.getWeRunData`（近 31 天步数）、`wx.shareToWeRun`（运动数据同步到微信运动排行榜，需"体育-在线健身"类目）、后台定位 API、map 组件、轨迹云服务（腾讯位置服务）
- **启示**：微信生态红利 = 分享到微信运动 + 好友排行 + 免安装

## 2. 对比结论

**市场格局**：国内分两派——大众健身派（Keep/悦跑圈/咕咚）主打跑步社交与商业化，轨迹只是入口；户外专业派（两步路/六只脚/行者）主打轨迹数据价值（导入导出、循迹、打点），商业化弱但粘性高。Strava 验证"免费记录+订阅增值"。

**共性功能**：GPS 实时记录标配；核心指标高度一致（里程、时长、配速、海拔、卡路里）；分享主流形态是"静态轨迹图+水印"，3D/动态回放仅付费产品；语音播报普及；统计支持日/周/月/总。

**差异化价值点**：
- 咕咚"运动瞬间"（照片打点→回忆册）
- 六只脚"多媒体脚印"（文字/图/视频挂载轨迹）
- 两步路"航点保留的 GPX/KML 导入导出"
- 行者"自定义表盘+分享长图"
- 悦跑圈"轨迹水印图+防作弊"
- Strava"Segment 路段排行+挑战赛"

**商业化分层**：课程会员（Keep）、赛事报名（悦跑圈/Keep）、硬件商城（咕咚/行者）、订阅增值（Strava/行者 PRO）、VIP（两步路）。

## 3. 对本项目的启示

### 值得借鉴的 10 个功能点（轻量定位）
1. GPS 实时记录 + 后台定位轨迹绘制 ✅（已入 P0）
2. **轨迹水印分享图**（数据+照片+轨迹叠加，一键存图/分享）✅（已入 P0，F21/F22）
3. **运动中打点**（拍照/休息/事件点，时间+地点+备注，轻量版"运动瞬间/脚印"）✅（已入 P0）
4. 轨迹静态图 + 动态回放（marker 移动，微信原生支持，低成本高感知）✅（已入 P2，F16）
5. 语音播报（每公里播报配速/里程/卡路里）➕ 新增 P2
6. 日/周/月/总统计看板 ✅（已入 P1）
7. 轨迹管理（列表、筛选、命名、日期/天气标注）✅（已入 P0）
8. **分享到微信运动**（`wx.shareToWeRun`，蹭微信生态流量）➕ 新增 P2，需"体育-在线健身"类目
9. **GPX/KML 导入导出**（导出留存可导入其他 App；导入循迹作 P2）✅（导出已入 P2）
10. 目标模式（距离/时长/配速目标 + 完成庆祝页）➕ 新增 P2

### 建议忽略的 5 个复杂功能
1. 3D 轨迹 / Flyover 飞越 — 开发成本高、移动端感知弱
2. 社交挑战赛 / 线上马拉松 — 运营重（赛事组织、奖牌物流、审核）
3. 完整社区（广场/关注/点赞）— 需内容审核与冷启动，只保留"薄社交"（分享）
4. 硬件生态（手环/跑鞋联动）— 重资产
5. 防作弊 / 专业训练分析（功率/TSS）— 超出轻量定位，GPX 导出即可覆盖进阶需求

### 一句话结论
轻量定位聚焦 **"记录快、分享美、数据看得懂"**——以 GPS 轨迹记录 + 打点 + 水印分享图为核心，用微信运动同步和 GPX 导出做差异化钩子，避开社区、赛事、硬件三大重资产方向。
